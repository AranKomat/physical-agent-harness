# Historical Specifications

These milestone specs, integration reports and the original BUILD_SPEC are
preserved design/provenance records. They are not parallel active architectures.
The [canonical overview](../architecture/overview.md) supersedes their directory
layouts; the [current queue](../experiments/queue.md) supersedes old next-step lists.

Navigation links and code paths have been migrated where possible. Installer
hashes, recorded model outcomes, schema/receipt identifiers, and historical
qualification limits retain their original meaning. Reproducing an exact earlier
experiment may require its original commit and private artifacts, not simply
running a historical command against today's tree.

Nothing in these documents grants a new model budget, motion permission, license
acceptance or qualification. Old overlays must be reviewed against current
contracts rather than applied by bypassing their hash checks.
